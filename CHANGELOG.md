# Changelog

## 1.1.0

- See which tabs are playing audio: a speaker icon marks the tab, and any window that contains one
- Mute or unmute any tab with one click, without leaving the popup
- New "Mute all playing" button silences everything at once
- The window you're browsing in the panel stays highlighted

## 1.0.0

- First release: list every window with its tab count, hover to see its tabs, click a tab to jump to it
- Windows listed most recently used first, with the current window on top
- Filter windows and tabs by typing
